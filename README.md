# HeatShield AI

Personalized Household Heatwave Preparedness Agent

## Problem
Generic heatwave alerts do not account for household-specific
vulnerabilities such as elderly members, children, outdoor workers,
housing conditions and cooling access.

## Proposed Solution
HeatShield AI is an AI-assisted preparedness agent that analyzes
household profiles and public heatwave information to generate
prioritized, personalized preparedness plans.

## Key Features
- Household vulnerability profiling
- Risk prioritization
- Heatwave/public guidance integration
- Personalized preparedness checklist
- Hindi/Hinglish guidance
- Voice interface
- Shareable family preparedness card
